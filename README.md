The base model is the MACE-matpes-pbe-omat-ft.model that can be downloaded from MACE's official website:
https://mace-docs.readthedocs.io/en/latest/guide/foundation_models.html

The base model, the e0s.json, example_config.yaml should be in a folder named "result"

The OUTCAR inputs should be in .xyz format and placed in a folder named "OUTCAR", this is the training and testing datas.
